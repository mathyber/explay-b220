# Браузер GO1 с HTTPS

`BROWSER.GO1` — простой текстовый браузер, программа формата GO1 с карты памяти.
В списке «Приложения» он называется **«Браузер»**. Его иконка — зелёный замок с дужкой
в виде волн сигнала ([apps/browser/browser.png](apps/browser/browser.png)).

Своё у него всё, кроме сети и файлов:
- **TLS** — BearSSL, версии 1.0–1.2;
- **корневые сертификаты** — набор Mozilla;
- **HTTP**, **разбор HTML**, **вёрстка** и **шрифты** с кириллицей (растровые шрифты JVM).

От прошивки браузер берёт только GPRS, сокеты, часы, таймер и экран — через API GO1.

Внутренняя память телефона не используется. Программа (228 КБ) лежит на карте. Пока
она открыта, занимает в куче приложений около 700 КБ и ещё 96 КБ под сжатые страницы.
Если этих 96 КБ нет, браузер просит у сайтов несжатые страницы.

## Что умеет

* Адреса `http://` и `https://`.
* Переадресации: 3xx и `<meta http-equiv="refresh">`.
* Ответы обычным потоком и `chunked`, сжатые gzip и deflate. По медленному GPRS
  страница приходит в 3–5 раз быстрее. Сжатый ответ копится целиком (до 64 КБ) и
  распаковывается в конце.
* Cookies, пока браузер открыт: домен, путь, `Secure`, удаление через `Max-Age=0`
  и прошедший `Expires`. Cookie для чужого домена не принимаются. При выходе
  cookies забываются.
* Формы: текстовые поля и пароли, скрытые поля, флажки, переключатели, списки
  `select`, `textarea`, кнопки `submit`, `image` и `<button>`. Отправка GET и
  POST (`application/x-www-form-urlencoded`, UTF-8). Форма без кнопки получает
  кнопку «Отправить».
* Кодировки UTF-8 и windows-1251.
* Из HTML: заголовок страницы, заголовки `h1`–`h6`, абзацы, переводы строк, списки
  (маркеры и нумерация), таблицы строками, ссылки, `alt` картинок,
  предварительно отформатированный текст, основные сущности (`&amp;`, `&laquo;`,
  `&#1234;` и т. д.).
* `script`, `style`, `svg`, `template` пропускаются.
* Строка без точки — это поиск через DuckDuckGo Lite.

Не умеет:
- JavaScript, CSS, картинки;
- cookies между запусками, brotli, HTTP/2, TLS 1.3.

Страница больше 60 000 символов обрезается.

## Управление

| Клавиша | Действие |
|---|---|
| вверх / вниз (2 / 8) | предыдущая / следующая ссылка или поле на экране, иначе прокрутка |
| влево / вправо (4 / 6) | страница вверх / вниз |
| OK (5) | открыть ссылку; на поле — изменить текст, поставить или снять флажок, выбрать переключатель, следующий вариант списка; на кнопке — отправить форму |
| левая экранная | адрес или поиск |
| правая экранная | назад; на первой странице — выход |
| `*` | обновить |
| `#` | стартовая страница |
| `0` | добавить страницу в закладки |

Поля форм на экране — серые рамки, выбранное поле — зелёное. Текст поля правится тем же
редактором, что и адрес, только левая экранная — «Готово».

Редактор адреса работает мультитапом:
- **2–9** — буквы: латиница как обычно, русские как на телефонах тех лет —
  2 абвг, 3 деёжз, 4 ийкл, 5 мноп, 6 рсту, 7 фхцч, 8 шщъы, 9 ьэюя;
- **1** — `. / : - _` (в русском режиме `. , ? ! - :`);
- **0** — пробел;
- **\*** — `? = & % + @ ! ~`;
- **#** — режим по кругу: `abc` → `ABC` → `абв` → `АБВ` → `123` (текущий виден внизу
  посередине);
  адрес открывается в `abc`, поле формы — в последнем выбранном режиме;
- **влево/вправо** — курсор;
- **вверх** — стереть всё;
- **правая экранная** — стереть символ (в пустой строке — отмена);
- **OK** или **левая экранная** — перейти.

## Сборка и установка

Нужны два файла, которых нет в git (в `analysis/toolchains/`):

* `bearssl-src/bearssl-0.6/` — распакованный https://www.bearssl.org/bearssl-0.6.tar.gz
  (SHA-256 `6705bba1714961b41a728dfc5debbe348d2966c117649392f8c8139efc83ff14`);
* `cacert.pem` — корневые сертификаты Mozilla в выгрузке curl: https://curl.se/ca/cacert.pem.

```powershell
.\.venv\Scripts\python.exe -m tools.build_browser [--card <образ карты>]
```

[tools/build_browser.py](tools/build_browser.py) делает три вещи:
1. Превращает сертификаты в trust anchors BearSSL, а шрифты JVM — в массивы C (`analysis/browser/browser_data.c`).
2. Компилирует [apps/browser/browser.c](apps/browser/browser.c) вместе с BearSSL.
3. Ставит программу на карту текущей сборки CUT.

BearSSL компилируется без предупреждений, в ARM-режиме и с кэшем объектов
(`analysis/toolchains/objects`). Причина ARM-режима: в Thumb у ARMv4T нет длинного
умножения `UMULL`, а на нём держатся 31-битные реализации RSA и эллиптических кривых.

## Сеть

GPRS поднимается так же, как в штатном браузере: вызывается его функция
`MMIBRW_AcitvieGPRS` (0x5991e6), и используется его профиль точки доступа.

Дальше работают сокеты прошивки (`0x2cfb32`…). TCP-соединение неблокирующее, программа
опрашивает его по таймеру окна раз в 50 мс. Сеть не активна, пока браузер не открыт.

В эмуляторе сеть включается кнопкой «Сеть…». Модель сети подключается в окне
«Приложения» так же, как в штатном браузере.

## Безопасность и ограничения

* **Сертификаты проверяются** по цепочке до корней Mozilla, по имени сайта и по дате.
  Дату берёт из часов телефона: если она неверна, сайты не откроются
  («Сертификат просрочен»).
* **Случайные числа для TLS — слабое место.** Аппаратного генератора в прошивке я не
  нашёл. Энтропия собирается так: SHA-256 от 64 КБ RAM задач MMI, времени, моментов
  нажатий и прихода пакетов. Между запусками её переносит `E:\BROWSER\SEED.BIN`: файл
  подмешивается при запуске и сразу перезаписывается, а потом ещё раз после каждой
  страницы по HTTPS. Первый запуск на новой карте всё равно слабый. Для банков и
  паролей такой TLS лучше не использовать.
* **Закладки** лежат в `E:\BROWSER\BOOKMARKS.TXT`: по строке на закладку, в формате
  «адрес, табуляция, название» (UTF-8). Удалять их пока можно только правкой файла.
* **Скорость в эмуляторе.** Цифры ниже сняты, когда эмулятор выполнял около
  0,5 млн инструкций в секунду. Сайты с цепочкой на RSA (DuckDuckGo Lite) открывались
  за 10–20 секунд. Цепочки с ECDSA P-384 (example.org за Cloudflare, Википедия,
  Let's Encrypt ECDSA) проверялись больше минуты, и сервер успевал разорвать соединение.
  С 2026-11-06 эмулятор считает срезами, около 20 млн инструкций в секунду
  (EMULATION_RU.md, «Скорость и время»). Время TLS заново ещё не измерено.
  На телефоне проверка должна занимать порядка секунды, но на железе ещё не проверено.
* **Сайты на TLS 1.3** без поддержки 1.2 не откроются («Сайт требует TLS 1.3»).
* **Русский текст** уходит в адрес и поля в UTF-8, поиск по-русски идёт через
  DuckDuckGo как есть.
* **Формы.** Скрытые поля с русскими буквами в значении портятся (атрибуты
  читаются как ASCII). Значения отправляются в UTF-8, даже если страница в
  windows-1251. Страница, полученная через POST, в истории остаётся адресом
  формы: «Назад» и `*` загружают её заново через GET.

## Проверка на ПК

`tests/test_browser_host.py` собирает `browser.c` под Windows (обвязка
[apps/browser/host_test.c](apps/browser/host_test.c): API GO1 заменён сокетами и
заглушками) и гоняет его против локального HTTP-сервера:
- gzip, zlib и «голый» deflate;
- cookies по пути и домену, удаление;
- формы всех видов: поля, флажки, переключатели, список, `textarea`;
- GET с кодированием значений, POST, форма без кнопки.

Обвязка принимает команды: `load URL`, `page` (текст страницы, `[n]` — ссылки,
`{n:значение}` — поля), `set N текст`, `ok N`, `request`, `cookies`, `status`.

## Проверено в эмуляторе (CUT)

Через реальный интернет компьютера:
- `http://info.cern.ch` — страница со списком и ссылками;
- `https://lite.duckduckgo.com/lite/` — TLS 1.2, X25519, сертификаты DigiCert на RSA;
- поиск «nokia» с русским текстом выдачи (UTF-8) и нумерованными результатами.

Проверить для телефона:
- переход по ссылке результата через переадресацию;
- скорость ECDSA P-384.
