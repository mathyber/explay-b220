# Браузер GO1 с HTTPS

`BROWSER.GO1` — простой текстовый браузер, программа формата GO1 с карты памяти.
В списке «Приложения» он называется **«Браузер»**. Его иконка — зелёный замок с дужкой
в виде волн сигнала ([apps/browser/browser.png](apps/browser/browser.png)).

Своё у него всё, кроме сети и файлов:
- **TLS** — BearSSL, версии 1.0–1.2;
- **корневые сертификаты** — набор Mozilla;
- **HTTP**, **разбор HTML**, **вёрстка** и **шрифты** с кириллицей (растровые шрифты JVM).

От прошивки браузер берёт только GPRS, сокеты, часы, таймер и экран — через API GO1.

Внутренняя память телефона не используется. Программа (214 КБ) лежит на карте, в RAM
занимает около 600 КБ кучи приложений, пока открыта.

## Что умеет

* Адреса `http://` и `https://`.
* Переадресации: 3xx и `<meta http-equiv="refresh">`.
* Ответы обычным потоком и `chunked`.
* Кодировки UTF-8 и windows-1251.
* Из HTML: заголовок страницы, заголовки `h1`–`h6`, абзацы, переводы строк, списки
  (маркеры и нумерация), таблицы строками, ссылки, `alt` картинок,
  предварительно отформатированный текст, основные сущности (`&amp;`, `&laquo;`,
  `&#1234;` и т. д.).
* `script`, `style`, `svg`, `template`, `select`, `textarea` пропускаются.
* Строка без точки — это поиск через DuckDuckGo Lite.

Не умеет:
- JavaScript, CSS, картинки и формы (кроме поиска из адресной строки);
- cookies, gzip, HTTP/2, TLS 1.3.

Страница больше 60 000 символов обрезается.

## Управление

| Клавиша | Действие |
|---|---|
| вверх / вниз (2 / 8) | предыдущая / следующая ссылка на экране, иначе прокрутка |
| влево / вправо (4 / 6) | страница вверх / вниз |
| OK (5) | открыть выделенную ссылку |
| левая экранная | адрес или поиск |
| правая экранная | назад; на первой странице — выход |
| `*` | обновить |
| `#` | стартовая страница |

Редактор адреса работает мультитапом:
- **2–9** — буквы;
- **1** — `. / : - _`;
- **0** — пробел;
- **\*** — `? = & % + @ ! ~`;
- **#** — переключение буквы/цифры;
- **влево/вправо** — курсор;
- **вверх** — стереть всё;
- **правая экранная** — стереть символ (в пустой строке — отмена);
- **OK** или **левая экранная** — перейти.

## Сборка и установка

Нужны два файла, которых нет в git (в `analysis/toolchains/`):

* `bearssl-src/bearssl-0.6/` — распакованный https://www.bearssl.org/bearssl-0.6.tar.gz
  (SHA-256 `6705bba1714961b41a728dfc5debbe348d2966c117649392f8c8139efc83ff14`);
* `cacert.pem` — корневые сертификаты Mozilla в выгрузке curl: https://curl.se/ca/cacert.pem.

```powershell
.\.venv\Scripts\python.exe -m tools.build_browser [--card <образ карты>]
```

[tools/build_browser.py](tools/build_browser.py) делает три вещи:
1. Превращает сертификаты в trust anchors BearSSL, а шрифты JVM — в массивы C (`analysis/browser/browser_data.c`).
2. Компилирует [apps/browser/browser.c](apps/browser/browser.c) вместе с BearSSL.
3. Ставит программу на карту текущей сборки CUT.

BearSSL компилируется без предупреждений, в ARM-режиме и с кэшем объектов
(`analysis/toolchains/objects`). Причина ARM-режима: в Thumb у ARMv4T нет длинного
умножения `UMULL`, а на нём держатся 31-битные реализации RSA и эллиптических кривых.

## Сеть

GPRS поднимается так же, как в штатном браузере: вызывается его функция
`MMIBRW_AcitvieGPRS` (0x5991e6), и используется его профиль точки доступа.

Дальше работают сокеты прошивки (`0x2cfb32`…). TCP-соединение неблокирующее, программа
опрашивает его по таймеру окна раз в 50 мс. Сеть не активна, пока браузер не открыт.

В эмуляторе сеть включается кнопкой «Сеть…». Модель сети подключается в окне
«Приложения» так же, как в штатном браузере.

## Безопасность и ограничения

* **Сертификаты проверяются** по цепочке до корней Mozilla, по имени сайта и по дате.
  Дату берёт из часов телефона: если она неверна, сайты не откроются
  («Сертификат просрочен»).
* **Случайные числа для TLS — слабое место.** Аппаратного генератора в прошивке я не
  нашёл. Энтропия собирается так: SHA-256 от 64 КБ RAM задач MMI, времени, моментов
  нажатий и прихода пакетов. Между запусками ничего не сохраняется. Для банков и
  паролей такой TLS лучше не использовать.
* **Скорость в эмуляторе.** Эмулятор выполняет примерно миллион инструкций в секунду,
  а настоящий процессор быстрее примерно в 100 раз. Сайты с цепочкой на RSA
  (DuckDuckGo Lite) открываются в эмуляторе за 10–20 секунд. Цепочки с ECDSA P-384
  (example.org за Cloudflare, Википедия, Let's Encrypt ECDSA) проверяются в эмуляторе
  больше минуты, и сервер успевает разорвать соединение. На телефоне это должно
  занимать порядка секунды, но на железе ещё не проверено.
* **Сайты на TLS 1.3** без поддержки 1.2 не откроются («Сайт требует TLS 1.3»).

## Проверено в эмуляторе (CUT)

Через реальный интернет компьютера:
- `http://info.cern.ch` — страница со списком и ссылками;
- `https://lite.duckduckgo.com/lite/` — TLS 1.2, X25519, сертификаты DigiCert на RSA;
- поиск «nokia» с русским текстом выдачи (UTF-8) и нумерованными результатами.

Проверить для телефона:
- переход по ссылке результата через переадресацию;
- скорость ECDSA P-384.
