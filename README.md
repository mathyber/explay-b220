Штатный браузер загружает страницу из реального интернета через экспериментальный
`--internet`: проверен HTTP-запрос к example.org и отображение ответа. DNS и TCP
обслуживает Windows, HTTP и TLS исполняет сама прошивка; адаптации сайтов нет.
SIM/регистрация пока реализованы на уровне служб прошивки (HLE), аппаратная SIM
ещё не эмулируется. В обычном окне нажмите **«Сеть…»**, включите интернет,
затем откройте браузер телефона. Для длинного адреса есть **«Открыть URL…»**.
[Запуск, экран и ограничения](INTERNET_RU.md).
Для воспроизводимых локальных тестов остаётся [режим `--http-test`](LOCAL_HTTP_RU.md).

**Добавлены все 23 кнопки телефона:** экранные клавиши, навигация, три вызова,
красная завершения/питания, цифры, `*` и `#`. Ввод поступает в оригинальные
обработчики прошивки через эмулируемые KPD и GPIO-прерывания.
[Запуск, управление и технические подробности](BUTTONS_RU.md).

Дважды щёлкните **`Explay B220.lnk`** или **`Start B220.cmd`**.
После загрузки нажимайте кнопки мышью либо используйте стрелки, Enter, цифры,
F1/F2 для экранных клавиш, Esc для красной. Три зелёные: SIM1 — F5,
SIM2 — F3, SIM3 — F4. Если появляется настройка даты/времени, подтвердите
каждую левой экранной клавишей.

В начале интерфейса CPU ставится на паузу; нажатие автоматически продолжает
работу. В окне есть пауза, перезапуск, масштаб, сохранение PNG и журнал.
Экран обновляется во время исполнения, виртуальная NOR сохраняется между
запусками. Скорость пока ниже настоящего телефона, холодная загрузка занимает
примерно 1–1,5 минуты на текущем компьютере. Первое открытие меню с картинками
может занимать десятки секунд.

Исправлен сдвиг экрана при выборе фона: [причина и проверка DMA](DISPLAY_FIX_RU.md).

Консольный конечный прогон с сохранением отчёта:

```powershell
.\run_emulator.ps1 -Frames 5
```

Исследована прошивка `S915D_B220_QCIF_N_TRI_M224V02.02B06`:
Spreadtrum SC6600L/L7A, ARM/Thumb big-endian. Извлечены компоненты PAC,
31 медиафайл, начальные таблицы памяти. Windows-стенд выполняет исходную
прошивку до интерфейса MMI и передаёт в неё нажатия клавиш. Полной эмуляции
всех устройств и поддержки J2ME пока нет.

Повторить анализ в подготовленном окружении:

```powershell
.\run_analysis.ps1
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Создать окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-analysis.txt
```

После клонирования распакуйте сохранённый в репозитории исходный ZIP в корень
проекта, затем выполните анализ для подготовки компонентов прошивки:

```powershell
Expand-Archive -LiteralPath .\Explay_B220_M224_V02.02_B06_20120720_FSPD.zip -DestinationPath .
.\run_analysis.ps1
```

Для первого запуска используйте `Start B220.cmd`: локальный `.lnk` не хранится
в Git. Окружение, распакованная прошивка и результаты в `analysis/` также
исключены из Git. В `analysis/` отслеживаются только рукописные заметки и три
исторических диагностических профиля; отчёты и снимки по ссылкам в документации
доступны после соответствующих локальных прогонов. Тестовые фикстуры остаются
в `tests/fixtures/`.

Анализ файлов выполняется офлайн; сеть эмулятора включается отдельно.
Исходный архив и
оригинальная распакованная папка сохранены без изменений.
