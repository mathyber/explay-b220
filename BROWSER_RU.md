# Браузер HTML + CSS для B220 (цели)

Статус на 2026-11-07: **этапы 2–4 сделаны, этап 5 частично.** Текстовый браузер
`BROWSER.GO1` работает: [BROWSER_GO1_RU.md](BROWSER_GO1_RU.md). Пока нет этапа 1
(CSS, PNG, просмотр файлов с карты), кеша картинок и настроек. Документ
фиксирует исходную цель, объём и порядок.

## Цель

Собственный браузер на C — нативная программа с карты памяти (`HTML.GO1`), как
Java-машина `JAVA.GO1`. Он показывает HTML с простым CSS **без JavaScript** на
экране 176×220: сначала файлы с карты, затем страницы из интернета по HTTP
и HTTPS.

Ориентир по возможностям — мобильные браузеры середины 2000-х (Opera Mini,
ранний Opera Mobile): одна колонка под ширину экрана, текст, ссылки, картинки,
формы.

## Почему без JavaScript

| Современный сайт требует | У нас есть |
|---|---|
| 2–10 МБ HTML, CSS и скриптов; после разбора — десятки и сотни МБ | около 1,4 МБ App Heap одним блоком ([MEMORY_RU.md](MEMORY_RU.md)) |
| JS-движок уровня V8; без него многие сайты пустые | даже малые движки (QuickJS) хотят несколько МБ и не тянут фреймворки |
| Сложная раскладка: flexbox, grid, веб-шрифты | слабый ARM, экран 176×220 |

Сайты, которые без JS ничего не показывают, в этот браузер не входят. Для них
отдельная возможная цель — режим через свой прокси (см. ниже).

## Объём

| Часть | Что поддерживаем |
|---|---|
| HTML | Разбор «грязного» HTML, как в браузерах: незакрытые и неправильно вложенные теги, сущности (`&amp;`, `&nbsp;`, числовые). Заголовки, абзацы, ссылки, списки, `<br>`, `<b>/<i>/<u>`, `<pre>`, `<blockquote>`, простые таблицы, `<img>`, формы (`input`, `textarea`, `select`, кнопки; GET и POST). `<script>` пропускаем, `<noscript>` показываем |
| Кодировки | UTF-8, Windows-1251, KOI8-R (`<meta charset>` и заголовок `Content-Type`) |
| CSS | `<style>`, `style=""`, внешние `.css`. Селекторы: тег, класс, id, потомок, группа. Свойства: `color`, `background-color`, `font-size`, `font-weight`, `font-style`, `text-decoration`, `text-align`, `display: block / inline / none / list-item`, `margin`, `padding`, `border`, `width`/`max-width` (ограничиваются шириной экрана), `white-space`. Каскад и наследование в упрощённом виде |
| Раскладка | Одна колонка шириной 176 пикселей, перенос по словам. `float`, flexbox, grid и позиционирование превращаются в блоки друг под другом. Таблицы — строками или упрощённой сеткой, если помещаются |
| Картинки | PNG (декодер уже есть в Java-машине), GIF (первый кадр), JPEG; уменьшение под ширину экрана; можно отключить |
| Шрифты | Растровые шрифты с кириллицей из Java-машины, размеры 12/14/16 |
| Навигация | Прокрутка, переход по ссылкам и полям стрелками, история «назад», закладки, ввод адреса |
| Память | Страница разбирается потоком прямо в компактный список строк и блоков для экрана; исходный HTML целиком не хранится. Цель — страницы до 100–300 КБ HTML в ~1,4 МБ |

## Не входит

* JavaScript и всё, что от него зависит.
* `@media`, анимации, переходы, веб-шрифты, SVG, `canvas`, видео и звук.
* Точное повторение вёрстки настольного сайта.

## Что уже есть в проекте

* **Запуск с карты:** загрузчик GO1N, поиск файлов, открытие по пути UCS-2,
  текст UCS-2 ([SD_APPS_RU.md](SD_APPS_RU.md)).
* **Готовые части Java-машины:** декодер PNG, растровые шрифты с кириллицей,
  чтение JAR/inflate (понадобится и для `Content-Encoding: deflate/gzip`)
  ([J2ME_RU.md](J2ME_RU.md)).
* **Сеть в эмуляторе:** прошивка сама проходит SIM, PDP, DNS и TCP через свой
  сокетный слой CMS (`cms.socket`, `cms.dns`, connect/send/recv/close). Режим
  `--internet` подключает настоящие DNS и TCP Windows; штатный браузер прошивки
  открыл example.org по HTTP ([INTERNET_RU.md](INTERNET_RU.md),
  [NETWORK_EMULATION_RU.md](NETWORK_EMULATION_RU.md)).
* **TLS прошивки устарел:** на `https://example.org/` сервер ответил на её
  ClientHello отказом `handshake_failure`. Поэтому HTTPS — свой, на компактной
  библиотеке (кандидат — BearSSL: TLS 1.2, десятки КБ памяти), с собственным
  набором корневых сертификатов.

## Этапы

| Этап | Результат | Условие готовности |
|---|---|---|
| 1. Просмотрщик с карты | `HTML.GO1` открывает `.html` из `E:\HTML\`: HTML, CSS, ссылки между локальными файлами, PNG | Набор страниц-образцов отрисовывается одинаково в сборке для Windows (снимки экрана) и в эмуляторе; тесты сравнивают пиксели ключевых мест |
| 2. Сеть в API GO1N | Обёртки над сокетами прошивки: подключение GPRS, DNS, TCP connect/send/recv/close | Нативная программа в эмуляторе (`--internet`) скачивает страницу по HTTP с локального сервера |
| 3. HTTP | Запросы GET/POST, перенаправления, chunked, gzip/deflate, cookies (в памяти), кодировки | Открываются локальные тестовые страницы и пара реальных HTTP-сайтов |
| 4. HTTPS | Свой TLS 1.2 (BearSSL), корневые сертификаты на карте | Открываются Википедия и `lite.duckduckgo.com`; время рукопожатия измерено в эмуляторе и на телефоне |
| 5. Удобство | Закладки, история, ввод адреса, формы, кеш картинок на карте, настройки (картинки вкл/выкл) | Поиск через `lite.duckduckgo.com` и чтение статьи Википедии проходят целиком с клавиатуры телефона |

Состояние этапов:
- 1 — не начат;
- 2 — готов (API GO1: GPRS, DNS, TCP);
- 3 — готов (GET/POST, переадресации, chunked, gzip/deflate, cookies в памяти,
  UTF-8 и windows-1251);
- 4 — готов в эмуляторе: RSA-сайты открываются, ECDSA P-384 в эмуляторе слишком
  медленный, на телефоне не проверен;
- 5 — частично: закладки, история, ввод адреса (латиница и кириллица) и формы есть;
  кеша картинок и настроек нет.

## Возможное продолжение: режим через прокси

Как Opera Mini: на своём сервере настоящий браузер открывает страницу целиком,
с JavaScript, и отдаёт телефону упрощённую разметку или картинку, принимая
клики и ввод. Так открывается почти любой сайт, но нужен свой сервер.
Возможная основа — готовые прокси для старых браузеров (например, WRP).
Решение — после этапа 4.

## Открытые вопросы

* Скорость на телефоне: разбор, раскладка, декодирование картинок, TLS-рукопожатие.
  До измерений на аппарате — только оценки по эмулятору.
* Сокетный API прошивки: насколько он пригоден для вызова из нативной программы
  (события, неблокирующий режим, одновременные соединения).
* Свободная память при активном GPRS-соединении — замерить.
* Делить ли код (шрифты, PNG, inflate) с Java-машиной общей библиотекой или
  копировать в каждую программу.
