# Пробная замена золотого акцента на зелёный

Запуск: **`Start B220 GREEN.cmd`**. Он создаёт отдельную копию текущего
`analysis/firmware-patches/sd-app/sd-app.bin`, перекрашивает найденный акцент
и открывает её в обычном окне. Основной образ не перезаписывается.

Для просмотра откройте **Мультимедиа** или другой длинный список и посмотрите
на правую полосу прокрутки. Экран экспериментального образа автоматически
не просматривался: визуальную проверку оставили пользователю.

## Что изменено

В исходном образе распознаны 567 встроенных растровых ресурсов с заголовком
`MB`: big-endian вариант BMP, 16 бит RGB565, compression `0x1003`.
Все 486 совпадений цвета `0xFEEE` в их пиксельных данных заменены на `0x07E0`.
Это светло-золотой RGB(255,223,115) → ярко-зелёный RGB(0,255,0).
Другие оттенки золотого пока не перекрашивались.

Совпадения находятся в одном ресурсе:

| Поле | Значение |
|---|---|
| Адрес в PS | `0x6D46C` |
| Размер ресурса | 5774 байта |
| Размер растра | 13×260 |
| Заменённые записи цвета | 486; повторяемые RLE-цвета могут давать несколько пикселей |

При исследовании совместимого снимка текущей прошивки зафиксированы чтения
этого ресурса при перемещении по списку «Мультимедиа». Цветовые слова читаются
штатным ARM-декодером, в частности инструкцией по `0x527778`.

Декодер использует пары байтов `(repeat,literal)`, затем `literal` цветовых
слов RGB565 и при ненулевом `repeat` ещё одно повторяемое цветовое слово.
`00 00` завершает строку. Сборщик проверяет ширину каждой строки, высоту,
границы ресурса и RGB-маски. Заменяются только позиции цветовых слов:
заголовки, команды RLE и совпадения байтов в машинном коде не затрагиваются.

## Файлы и проверки

- `analysis/firmware-patches/green-theme/source-copy.bin` — точная копия текущего PS.
- `analysis/firmware-patches/green-theme/b220-green.bin` — изменённый вариант.
- `analysis/firmware-patches/green-theme/manifest.json` — хеши и список изменений.
- [Сборщик](tools/build_green_theme.py).

SHA-256 исходного текущего образа:
`b9da6a50a6c8a0c66d3f1d7e28107b28949d86aee47519c456a57cfa551eb104`.

SHA-256 зелёного варианта:
`4ba01e40f340927b708432ee2f63f9a227ab703eb08ead41846a1d7ad737a42d`.

Размер PS сохранён — 7623420 байт. Проверены точные границы изменений,
повторный разбор всех растров после замены, соответствие копии исходному
образу и допустимость нового PS для эмулятора. Холодная загрузка и проверки
экранов зелёной версии не запускались по просьбе пользователя.

У экспериментального образа собственные NOR/SD по SHA-256. Ярлык готовит
на его отдельной карте два примера приложений, сохраняя уже существующие
файлы. Карта основного образа не меняется.

Повторить сборку без запуска окна:

```powershell
.\.venv\Scripts\python.exe -m tools.build_green_theme --prepare-card
```

Можно выбрать другой исходный PS через `--source`. Сборщик копирует переданный
образ без пересборки его C-кода и затем перекрашивает все найденные совпадения
в поддерживаемом формате растров.
