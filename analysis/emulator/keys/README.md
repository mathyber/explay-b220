# Проверки клавиш, 1 ноября 2026

Подтверждённый путь: `13-gpio-end.png` — выход из меню на главный экран,
`14-dial-one.png` — набор `1`, `15-dial-twelve.png` — набор `12`.
Кнопка End проходит через GPIO3 / IRQ6 и даёт native-код 2.
`call_1..3.png` и `../call-keys-check.json` подтверждают разные коды трёх
зелёных клавиш: 1, 0x1a и 0x1b. Наличие ввода не означает работу модема.

Файлы `07..12` — отвергнутые гипотезы о красной клавише. Названия
`back-home`, `real-end` и `dial-*` в этих файлах не подтверждают результат:
коды 0x0b и 1 не выполняли выход. На последних кадрах была папка сообщений.
В частности, исследовательские checkpoint-файлы `dialer.pkl.gz` и
`real-dialer.pkl.gz` содержат Inbox. Корректный checkpoint с набором `12` —
`../checkpoints/gpio-dialer.pkl.gz`.

`01..06` показывают настройку даты, времени и вход в меню. Первый
`02-soft-left` останавливался на RAM DMA до реализации копирования.

Полная проверка окна находится уровнем выше: `window-key-stage-1..5.png`,
`window-key-test.json/html`, `window-key-check.json`.
